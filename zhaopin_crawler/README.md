# 智联招聘 岗位采集 + 智能分类工具

一键从智联招聘抓取几百个岗位的基本信息（岗位、薪资、公司、行业、城市、经验、学历、技能、公司性质、链接），自动做**两级分类**和**统计分析**，导出成一个带图表的 Excel。

> 仅用于个人学习与求职分析。请控制采集频率，遵守网站 robots 协议与用户协议，不要用于商业转售或骚扰性抓取。

## 二、它怎么抓的（实测结论，2026-10-25）

### 1. 不需要登录

智联的检索页 `https://sou.zhaopin.com/?jl=城市码&kw=关键词` 是**服务端渲染**的，
岗位数据直接写在页面的 `window.__INITIAL_STATE__.positionList` 里（每次 20 条）。
这个页面匿名就能看，**所以本工具不需要扫码登录**，打开就能抓。

### 2. 但必须有真实浏览器

连续用 `requests` 直接请求，从第 2 次开始就会被跳到
「Security Verification」验证页（一个约 2KB 的空白页）。
用 **Playwright 驱动本机 Edge**（真实浏览器指纹）就不会被拦。

### 3. 抓几百条靠"组合累加"

该检索页**不支持翻页**（实测 `hasMore=False`，`?p=2` 返回的还是第一页），
每个「关键词 × 城市」组合固定 20 条。所以岗位总量 = 组合数 × 20：

- 8 个关键词 × 8 个城市 = 64 个组合 → 理论上限 1280 条
- 去重后按 `-m` 参数截断（默认 600 条）

想抓更多就多加关键词/城市，或调大 `-m`。

```bash
python main.py                        # 正式采集（8 关键词 × 8 城市，上限 600 条）
```

## 六、分类与薪资口径

**分类**：先用岗位名称匹配关键词（先具体后宽泛），匹配不上再用技能标签兜底，
仍未命中的归入「其他/未分类」。规则在 `classifier.py` 的 `CATEGORY_RULES`，加一行即可：

```python
("技术研发", "音视频开发", ["音视频", "webrtc", "ffmpeg"]),
```

当前 15 个一级分类：教育/培训、技术研发、产品、设计、运营、市场/销售、人力/行政、
财务/法务、供应链/生产、客户服务、教育/培训、医疗/健康、传媒/内容、房地产/建筑、管培/储备。

**薪资**：优先取智联返回的 `salaryReal` 数字区间（元/月）折算成「千元/月」；
`·13薪`/`·14薪` 按实际月数估算年薪；金额过小（如 `150-300元`）判为按次/课时计薪，
标记「按次计薪」且**不并入平均月薪**，避免把统计拉偏。

## 七、常见问题

**Q：一条都没抓到 / 页面空白？**
A：多半是被反爬拦了（页面标题变成 `Security Verification`）。等 10 分钟再试；先跑 `python check_env.py` 看第 5 项。

**Q：抓到的条数比预期少？**
A：每个组合固定 20 条且不翻页，去重后数量会减少。加关键词或城市（`-k`、`-c`）即可。

**Q：报错 `Target page, context or browser has been closed`？**
A：浏览器窗口被关了。重跑一次，抓取过程中别关那个窗口。

**Q：`--headless` 跑不动？**
A：智联能识别无头浏览器，程序会自动切成有窗口模式重试；建议直接不加这个参数。

**Q：Excel 提示被占用、多出一个带时间戳的文件？**
A：说明原文件正在 Excel 里打开，程序自动另存新文件。关掉 Excel 再跑即可。

**Q：想加城市？**
A：改 `config.py` 的 `CITY_CODES`，格式 `"城市名": "三位编码"`。编码获取：浏览器打开智联搜索页切到该城市，地址栏 `jl=` 后面那三位数字。

## 八、已验证 / 已知限制

**已实测通过（2026-10-25）：**

- 20 个城市编码逐个核对（北京 530、上海 538、杭州 653…）；
- 连续 20 次翻页抓取无拦截，单组合稳定返回 20 条；
- 真实抓取北京·Python：20 条真实岗位，18 条带有效薪资，分类/统计/导出全链路正常；
- 演示模式 600 条秒级跑通 9 表 Excel；
- 浏览器窗口被关闭、Excel 占用文件等情况都有兜底提示。

**已知限制：**

- 每个组合只有 20 条（站点限制，不是代码问题）；
- 站点改版后 `__INITIAL_STATE__` 结构可能变化，届时改 `parser.py` 的字段映射即可；
- 「按次/课时」类岗位不计入平均月薪统计。
